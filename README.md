# 📊 E-Commerce Sales Analysis

## 📌 Project Overview

This project analyzes e-commerce sales data using Python to understand product performance, category sales, regional performance and monthly sales trends.

---

## 🎯 Problem Statement

E-commerce businesses generate large amounts of sales data. Analyzing this data helps businesses understand which products, categories, regions and months contribute the most to overall revenue.

---

## 💡 Solution

This project performs data cleaning, feature engineering, sales analysis and visualization to identify useful business insights.

The analysis includes:

- Total revenue
- Total orders
- Total units sold
- Product-wise revenue
- Best-selling products
- Category-wise sales
- Region-wise sales
- Monthly sales trends
- Average order value

---

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Google Colab
- GitHub

---

## 🧹 Data Preparation

- Checked missing values
- Checked duplicate records
- Converted dates into datetime format
- Created a Sales column
- Created a Month column

---

## 📊 Business Analysis

The project analyzes:

- Overall sales performance
- Product performance
- Category performance
- Regional performance
- Monthly performance
- Average order value

---

## 📈 Visualizations

- Revenue by Product
- Revenue by Category
- Revenue by Region
- Monthly Sales Trend
- Units Sold by Product

---

## 🔍 Key Insights

- Electronics contributed strongly to overall revenue.
- Laptops were among the major revenue-generating products.
- Revenue and product quantity provide different views of product performance.
- Regional analysis identifies the strongest sales markets.
- Monthly analysis helps identify changes in sales performance over time.
